# Swarnim Sugandh - Personal Portfolio 🚀

Welcome to the repository for my personal portfolio website! This project is a fully responsive, visually dynamic, and interactive showcase of my skills, certifications, and projects as a software developer.

🔗 **Live Website:** [Insert Live Link Here] *(e.g., https://swarnim91.github.io/My-Portfolio)*

---

## 🎨 Features

- **Modern Glassmorphism UI:** A sleek, dark-themed aesthetic with blurred, translucent cards and dynamic cyan (`#00ffcc`) accents.
- **Fully Responsive:** Beautifully optimized across all devices (Desktop, Tablet, and Mobile).
- **Dynamic Typing Animation:** A continuous, professional typing effect in the Hero section (powered by Typed.js) that cycles through my professional roles.
- **Interactive Navigation:** Sticky glass header with a smooth, slide-down mobile hamburger menu that intelligently closes on click or escape.
- **Floating Label Contact Form:** A clean, space-saving contact section that utilizes modern floating-label CSS transitions.
- **Zero Frameworks:** Built purely with **HTML5**, **CSS3**, and **Vanilla JavaScript** to ensure ultra-fast load times.

## 🛠️ Technologies Used

* **HTML5:** Semantic structuring.
* **CSS3:** Custom properties, CSS Grid & Flexbox layouts, animations, media queries, and glassmorphism.
* **JavaScript (Vanilla):** DOM manipulation for mobile navigation.
* **Typed.js:** Library used for the hero section typing animation.

## 🚀 How to Run Locally

Since this is a static website with no backend dependencies, running it locally is incredibly easy:

1. Clone the repository:
   ```bash
   git clone https://github.com/swarnim91/My-Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd My-Portfolio
   ```
3. Open `index.html` in your favorite web browser, or use an extension like **Live Server** in VS Code.
